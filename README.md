Todo se controla a traves del codigo "menu". 
Para poder ejecutar el programa, necesitara crear previamente la base de datos llamada "recursos_en_salud" dentro de MySQL
El programa cuenta con 2 opciones para insertar los datos en la base de datos, por medio de un Web scraping o desde archivos csv (para facilitar la revision)
Para la ejecucion del Web scraping se necesita una buena conexion a internet, debido a que la pagina donde se extraen los datos, no esta muy bien optimizada y tiene muchos impedimentos. 
Se debe ejecutar el dashboard unicamente si ya se insertaron los dato en MySQL
Para salirse del dashboard, debe presionar ctrl + c dentro de la consola, de otra forma, causara un error dentro del programa. 
Finalmente para salir del programa, escriba 4 en la consola.
